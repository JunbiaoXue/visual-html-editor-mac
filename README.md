# 网页可视化编辑器

一个使用 Swift、AppKit 和 WebKit 编写的 macOS 本地 HTML 编辑器。

支持打开和保存 HTML、直接编辑页面文字、插入和替换图片、设置图片宽度，以及逐行编辑 SVG 文本。支持 ⌘O、⌘S 和 ⌘Q。

## 构建

需要 macOS 和 Xcode Command Line Tools。运行：

```sh
./build.sh
```

应用生成在 `build/网页可视化编辑器.app`。本地签名不等同于 Apple 公证，首次打开可能需要在系统设置中允许。

## 当前限制

- SVG 的形状、图表数据和布局不能直接拖动编辑。
- 尚未实现未保存修改提醒；推荐使用“另存为”。
- 保存可能重写 HTML 的结构格式。带有相对路径资源的文件另存到其他目录时，资源链接可能失效。
- 复杂网页的脚本、样式和编辑体验尚未全面测试。
